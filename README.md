# JetBrains Mono for AERA

Data-only Theme Engine extension that adds JetBrains Mono as an AERA interface font.

The font comes from the official [JetBrains Mono repository](https://github.com/JetBrains/JetBrainsMono) and is distributed under the SIL Open Font License.

## Plugin Details

- **Plugin ID:** `font-jetbrains-mono`
- **Type:** `theme-extension`
- **Entry:** `font`
- **Font Family:** `JetBrains Mono`
- **Host API:** `2`
- **Protocol Version:** `1`

## Installation

1. Download or copy `JetBrains-Mono-1.0.0.aerap` to your device storage (`/sdcard/`).
2. Open **Files** or **Plugin Manager** in AERA Recovery.
3. Select `JetBrains-Mono-1.0.0.aerap` and confirm installation.
4. Navigate to **Theme Engine > Typography** and select **JetBrains Mono**.
